# JipperKeyViewer Display

JipperKeyViewer Display는 **A Dance of Fire and Ice**의 서드파티 모드를 기반으로 재구성 및 확장 개발한 키 매핑 표시 프로그램입니다. 다양한 기능을 추가했으며 더 많은 사용자가 편리하게 사용할 수 있도록 개선했습니다.

**방송**, **녹화** 또는 **게임 오버레이**에 사용할 간단하고 편리하면서도 다기능인 키 표시 프로그램이 필요하다면, 필요한 기능을 여기에서 모두 찾을 수 있습니다!

## 시스템 요구 사항 및 실행

프로그램 실행에는 다음 환경이 필요합니다.

- **운영체제:** `Windows 10/11`
- **GPU:** `Direct3D 11` / `Direct2D`를 지원하는 그래픽 카드 및 드라이버
- **프레임워크:** `.NET 8 Desktop Runtime (x64)`

프로그램 실행 중 GPU 초기화 또는 `Present`가 실패하면 CPU 호환 렌더링 모드로 자동 전환됩니다.

`Release`에는 다음 두 가지 프로그램 버전이 제공됩니다.

- `JipperKeyViewer.exe`
- `JipperKeyViewer(.NET).exe`

시스템에 필요한 .NET 프레임워크가 설치되어 있지 않으면 `JipperKeyViewer.exe`가 필요한 런타임의 다운로드 안내를 표시합니다.

.NET 프레임워크가 포함된 `JipperKeyViewer(.NET).exe`를 다운로드하면 프로그램에 포함된 .NET 런타임을 사용하여 바로 실행할 수 있습니다.

> [!NOTE]
> 이 버전은 일반적으로 .NET 런타임을 정상적으로 다운로드할 수 없는 사용자를 위한 호환 버전입니다. 대신 시스템 리소스를 더 많이 사용합니다.

## 주요 기능

### 1. 키 표시 및 소스 캡처

키 표시는 이 프로그램의 가장 핵심적이고 기본적인 기능입니다.

풀사이즈 키보드 레이아웃을 제외한 나머지 사전 설정 레이아웃은 리듬 게임에 맞춰 설계되었으며, 아래에서 소개할 키 레인 기능도 포함됩니다.

**소스 캡처:**

OBS Studio와 같이 장면 구성을 지원하는 녹화 및 방송 프로그램에서 키 표시 창을 간편하게 캡처하여 장면에 표시할 수 있습니다. 창의 기본 투명 기능도 지원합니다.

OBS Studio에서 캡처하는 방법을 예로 들면 다음과 같습니다.

장면에 **게임 캡처** 소스를 추가하고 모드를 **특정 창 캡처**로 설정한 다음, 창 목록에서 `Jipper Key Viewer Diaplsy`를 선택합니다. 아래 옵션에서 **투명도 허용**을 활성화합니다. 아래 이미지를 참고하세요.

![OBS Studio 게임 캡처 설정](https://github.com/XueBaoT/JipperKeyViewer-Display/releases/download/Picture/OBS-1.png)

**확인**을 클릭하면 장면에 KeyViewer 창이 투명하게 표시됩니다. 아래 이미지를 참고하세요.

![OBS Studio 투명 캡처 결과](https://github.com/XueBaoT/JipperKeyViewer-Display/releases/download/Picture/OBS-2.png)

### 2. 설정 페이지

KeyViewer 표시 창을 마우스 오른쪽 버튼으로 클릭하면 컨텍스트 메뉴를 열고 설정 페이지로 이동할 수 있습니다.

![KeyViewer 설정 페이지](https://github.com/XueBaoT/JipperKeyViewer-Display/releases/download/Picture/setting-main.png)

또한 `설정` > `키 설정` 페이지에서 전역 단축키를 지정하여 설정 페이지를 열 수도 있습니다. 이를 통해 기능 옵션을 빠르게 변경할 수 있습니다.

기본 단축키는 `F8`입니다.

---

### 3. 키 레인

키 레인은 현재 키 입력 방식과 상태를 실시간으로 확인하고 표시하는 기능입니다.

![키 레인 효과](https://github.com/XueBaoT/JipperKeyViewer-Display/releases/download/Picture/rainkeys.png)

풀사이즈 키보드 레이아웃(60K/75K/108K)을 제외한 모든 레이아웃에서 키 레인을 지원하며, 키 매핑을 사용자 지정할 수 있습니다.

ADOFAI용 키 레인에는 **GhostRain(고스트 레인)** 옵션도 제공되며, 설정 패널에서 활성화할 수 있습니다.

---

### 4. 사용자 지정

설정에는 키 표시 화면을 원하는 모습으로 꾸밀 수 있는 다양한 옵션이 제공됩니다. 몇 가지 설정만 변경해도 자신만의 화면을 만들 수 있습니다!

색상부터 텍스트 스타일에 이르기까지 여러 항목을 설정할 수 있으며, 개별 설정 항목은 여기에서 자세히 설명하지 않습니다.

---

### 5. 설정 구성 가져오기 및 내보내기

`설정` > `일반` 페이지에서 내보낼 사용자 지정 구성을 선택한 다음 `.jkv` 구성 파일로 저장할 수 있습니다.

프로그램을 처음 실행한 후 시스템을 재시작하면 `.jkv` 확장자가 프로그램과 자동으로 연결되고 파일 아이콘도 등록됩니다.

구성 파일을 더블 클릭하여 설정을 적용하거나, 파일을 KeyViewer 표시 창으로 직접 드래그하여 적용할 수 있습니다.

---

### 6. 전역 오버레이

화면에서 키 입력 상태를 실시간으로 확인하고 싶다면 이 기능을 사용하여 모니터에 투명한 전역 KeyViewer 오버레이를 표시할 수 있습니다.

아래 예시를 참고하세요.

![전역 오버레이 효과](https://github.com/XueBaoT/JipperKeyViewer-Display/releases/download/Picture/global_layered.png)

> [!WARNING]
> 전역 오버레이 기능을 활성화하면 창이 완전히 마우스 클릭을 통과시키므로 마우스로 어떠한 상호작용도 할 수 없습니다.
>
> 오버레이의 크기나 위치를 조정해야 한다면 이 기능을 활성화하기 전에 먼저 창의 크기와 위치를 조정하세요.
>
> 전역 오버레이를 끄려면 설정에서 지정한 전역 단축키로 설정 페이지를 열거나, 작업 표시줄 알림 영역의 시스템 트레이 아이콘을 마우스 오른쪽 버튼으로 클릭하여 비활성화할 수 있습니다.
>
> 또한 이 기능을 활성화하면 캡처 대상 창을 사용할 수 없게 되므로 OBS Studio의 **게임 캡처** 소스가 즉시 작동하지 않게 됩니다.

*이 기능을 제안해 주신 @到处乱跑的隐藏者 님께 특별히 감사드립니다.*

## 성능 및 호환성

### 성능

프로그램은 Alpha 및 Beta 테스트 단계에서 광범위한 테스트를 거치지 않았습니다. 대부분의 경우 성능 추정치는 개발자의 장비에서 진행한 테스트 결과만을 바탕으로 합니다.

현재 `JipperKeyViewer.exe`는 대부분의 장치에서 원활하게 실행할 수 있을 정도의 시스템 리소스를 사용합니다. 다만 장치의 사양이 낮으면 다른 프로그램과 함께 실행할 때 다음과 같은 문제가 발생할 수 있습니다.

- 프레임 저하
- 높은 CPU 사용률
- 눈에 띄는 입력 지연

이는 반드시 코드 구현상의 결함 때문인 것은 아닙니다. 이 프로그램은 키보드 입력을 캡처하기 위해 저수준 훅을 사용합니다. 성능이 낮은 CPU가 자주 높은 부하 상태에 놓이면 훅이 다른 작업과 처리 시간을 두고 경쟁하게 되어 입력 지연이 증가할 수 있습니다. 여러 키를 빠르게 입력할 때 이러한 현상이 특히 두드러집니다.

### 호환성

프로그램의 호환성은 아직 충분히 검증되지 않았습니다.

주로 `Windows 10/11 x64` 환경을 대상으로 개발되었습니다.

`Windows 7/8` 또는 `ARM64`와 같은 다른 환경은 지원되지 않을 수 있습니다. 이러한 환경에서 프로그램이 안정적이거나 정상적으로 실행되지 않는다는 사실을 직접 확인했음에도 지원되지 않는 환경에서 사용하기로 선택한 경우, **시스템 충돌이나 데이터 손실을 포함하되 이에 국한되지 않는 모든 결과에 대해 개발자는 책임을 지지 않습니다.**

*꼭 사용해야 한다면 AI에게 소스 저장소를 복제하고 수정한 뒤, 해당 환경에서 사용할 수 있는 버전으로 빌드해 달라고 요청해 볼 수 있습니다.*
