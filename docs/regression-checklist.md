# 回归测试清单 / Regression Checklist

> P1.3 补丁合并的最小验收集。涉及 UI/渲染/输入的改动必须跑对应分组。

## A. 构建与启动

- [ ] `dotnet build -c Release --no-incremental`：0 warning / 0 error
- [ ] 直接双击桌面 `JipperKeyViewer.exe` 启动
- [ ] 单实例：再次启动不产生第二个进程
- [ ] 托盘图标/菜单正常，退出无残留进程
- [ ] 配置目录可读写，日志正常生成

## B. 普通窗口

- [ ] 普通模式透明/半透明显示正常
- [ ] 拖动、缩放不变形（`ResizeBuffers` 路径）
- [ ] 置顶、任务栏显示、关闭行为正常
- [ ] OBS 窗口/游戏捕获正常，边缘无黑块/色块
- [ ] `JKV_GPU=0` 强制 CPU 仍可运行

## C. 覆盖层

- [ ] 开启覆盖层后无边框、置顶、不抢焦点
- [ ] 任务栏隐藏、位置锁定
- [ ] 逐像素透明，背景不黑/不白
- [ ] 跨进程点击穿透（设置/游戏窗口可被点击）
- [ ] 覆盖层关闭后完整还原普通窗口
- [ ] 开→关→开 3 次不黑屏、不漂移、不崩溃

## D. 输入与计数

- [ ] 高频连打 20–30 秒，输入无明显延迟
- [ ] 每键计数、KPS、Total 变化正确
- [ ] 千分位开/关正确
- [ ] KPS/Total 标签与数字同一 baseline（换字体/字号仍对齐）
- [ ] 改键捕获、Esc 取消、按键注册正确
- [ ] 注入键/回放键不被误计数

## E. 布局与视觉

- [ ] 16K 普通/覆盖层
- [ ] 75K、108K 普通/覆盖层
- [ ] 键帽圆角/描边/渐变/光晕/按压动画
- [ ] 键雨：触发、跟随缩放、松手淡出、溢出收缩
- [ ] 字体切换（MapleStory / CJK / 自定义）
- [ ] 每键颜色、每键字号

## F. 设置与持久化

- [ ] 设置窗打开/关闭，保存后重启保持
- [ ] 语言切换（中/英/韩）
- [ ] 主题跟随系统
- [ ] 方案切换/另存/重命名/删除
- [ ] `.jkv` 导入/导出、重名提示、失败回滚
- [ ] 拖放 `.jkv`、命令行打开 `.jkv`
- [ ] 旧配置（缺字段/旧键）加载不崩、默认值正确

## G. 性能与资源

- [ ] CPU < 8%，GPU < 8%
- [ ] 覆盖层 60fps，无明显掉帧
- [ ] 设置关闭时私有工作集约 100–120MB
- [ ] 设置打开过约 150MB 以内
- [ ] 连续运行 10 分钟，内存无持续增长
- [ ] 关闭后进程/句柄释放

## H. 补丁合并专项

- [ ] 合并 `TextLayout` 后：计数/KPS/Total 视觉与合并前一致
- [ ] 合并 `ConfigMigration` 后：旧配置仍可加载
- [ ] 合并 `RendererFactory`/`OverlayController` 后：普通/覆盖层切换一致
- [ ] 保留 `DCompOverlayBackend` 后：穿透/透明/DComp 正常
- [ ] 保留 OBS WGC 交换链契约后：OBS 捕获正常
